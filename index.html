How it works

A camera feeds video into a Python YOLO detector. The detection count is sent to the ESP32 over serial. A cloud data relay can publish the latest readings so this public website can display them from anywhere.

Monitoring details

This page is designed to show the latest cloud-published reading. It does not invent counts: until the data source is configured, values remain unavailable. The camera computer must be online and running for updates to continue.

Privacy note: This page displays aggregate counts only. Avoid publishing camera footage or personal information.
